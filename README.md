# Ride-Hailing System Dynamics

A University of Tehran project by Nima Ansaripour on how changes in driver supply affect trip demand and fares in Chicago. The model uses monthly data from July 2022 to December 2025.

- [Report](report.pdf)
- [Vensim models](models/) — start with `SFD.mdl` for the base simulation or `CLD.mdl` for the causal loop diagram.
- [Policy results](policy-results.xlsx) — commission reduction and a $15 minimum fare, each tested under unemployment and operating cost shocks.

The report lists a 25% commission for Policy 1. The supplied Vensim files set it to 20% after month 15.
